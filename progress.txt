# Ralph Progress Log
Started: 2026-01-06

## Codebase Patterns

- **Express App Structure**: Separate app configuration (`app.js`) from server startup (`index.js`) for testability
- **Testing**: Use Node.js built-in test runner (`node:test`) with `.test.js` suffix, start server in `before()` hook
- **Configuration**: Use environment variables with sensible defaults (PORT=3000, FRONTEND_URL=http://localhost:5173, DB_PATH)
- **Backend Location**: `backend/` directory at project root
- **Database**: Use `better-sqlite3` for synchronous SQLite operations; use `:memory:` for tests via `process.env.DB_PATH`

## Key Files

- `backend/src/app.js` - Express app configuration
- `backend/src/index.js` - Server entry point
- `backend/src/db.js` - Database module (SQLite)
- `backend/src/*.test.js` - Test files

## 2026-01-07 - US-002

- What was implemented:
  - SQLite database using better-sqlite3 package
  - Users table with id (INTEGER PK), email (TEXT UNIQUE NOT NULL), password_hash (TEXT NOT NULL), created_at (TEXT DEFAULT datetime)
  - Tasks table with id (INTEGER PK), user_id (INTEGER FK NOT NULL), title (TEXT NOT NULL), description (TEXT), is_completed (INTEGER DEFAULT 0), created_at (TEXT DEFAULT datetime)
  - Foreign key from tasks.user_id to users.id with ON DELETE CASCADE
  - Database module exports: getDb(), initDb(), closeDb(), resetDb()
  - Comprehensive test suite verifying all columns, constraints, and relationships

- Files changed:
  - `backend/package.json` - Added better-sqlite3 dependency
  - `backend/src/db.js` - Database initialization module
  - `backend/src/db.test.js` - Tests for database schema
  - `backend/AGENTS.md` - Added database patterns
  - `backend/.gitignore` - Added data/ directory

- **Learnings:**
  - Use `PRAGMA foreign_keys = ON` to enable foreign key enforcement in SQLite
  - Use `PRAGMA journal_mode = WAL` for better concurrent read/write performance
  - Store dates as TEXT with SQLite datetime() function for default values
  - Use `:memory:` for in-memory test databases via environment variable
  - better-sqlite3 is synchronous which simplifies code but blocks the event loop
